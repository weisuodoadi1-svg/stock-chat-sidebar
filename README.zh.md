# A 股聊天侧栏浏览器插件

[English](README.md) | 中文

这个免构建的 Manifest V3 扩展会在 zx017 聊天页右侧增加固定的股票观察栏。聊天功能保持可用，侧栏同时显示 A 股行情、当天分时与成交量、实时 5 日、10 日和 20 日均线，并支持自选排序和自定义提醒。

## 安装

1. 在 Arc 打开 `arc://extensions`，在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。如果 Arc 将 Chromium 设置页重定向，也可以使用 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择下载后包含 `manifest.json` 的仓库目录。
4. 打开或刷新 [zx017 聊天页](https://pc.zx017.net/vueapp/uc/chatting?forum_id=157)。右侧空白区域出现暖色浅底的“我的股票”面板即表示加载成功。

修改这个目录中的任意文件后，需要在扩展管理页重新加载扩展并刷新聊天标签页。扩展直接使用目录中的文件，不需要执行构建。

## 使用自选股

首次安装时自选股列表为空。在搜索框输入中文股票名称、六位代码或拼音，然后从联想列表选择正确的沪深 A 股；也可以用方向键和回车操作列表。

每张卡片都有删除按钮、均线提醒快捷开关和“设置”按钮。价格、涨跌幅及均线提醒条件与自选股一起保存在 `chrome.storage.local` 中，关闭标签页或浏览器后仍会保留。顶部排序菜单可按原顺序、已触发提醒、涨幅、跌幅或股票代码排列；排序方式仅在当前页面有效。

## 阅读卡片和提醒

卡片显示最新价、涨跌额、涨跌幅、昨收、实时 MA5、MA10、MA20 以及距离 MA5 的百分比。分时图绘制价格线、黄色均价线、分钟成交量柱和分时高低点；高低点是当前分钟价格采样的极值，不是逐笔成交的精确日内极值。左侧是价格，右侧是相对昨收的百分比，虚线中轴是 0%。横轴固定覆盖 09:30–11:30、13:00–15:00；盘中曲线按实际交易时间向右推进，尚未交易的时段保持空白。鼠标移入图表时，十字光标吸附到最近一分钟并显示时间、价格、均价、涨跌幅和成交量；聚焦图表后也可用左右方向键查看。

页面可见时每 15 秒刷新一次行情。顶部刷新按钮可以立即更新，箭头按钮可以把面板收成窄条。刷新失败时会保留最近一次有效行情并标记对应卡片，不会显示虚假的零价格。

提醒可设置价格上限/下限、涨跌幅上限/下限，以及一条 MA5、MA10 或 MA20 的高于/低于条件。条件首次从未触发变为触发时会发送一条桌面通知；持续满足条件不会每 15 秒重复通知。提醒检查仅在聊天页面打开且可见时运行。实时均线会用最新分钟价格替换当日收盘价；如果日线源尚未加入当天数据，则使用最近的已完成交易日收盘价和最新价计算。

## 数据、权限与隐私

内容脚本只在 `https://pc.zx017.net/vueapp/uc/chatting*` 运行，并挂载一个关闭的 Shadow DOM 宿主，页面脚本无法通过 `shadowRoot` 检查侧栏界面。它不会读取或传输聊天内容、Cookie、凭据或页面存储。

后台 service worker 使用东方财富获取名称和代码联想。日线和分钟行情优先请求腾讯；前一提供方失败时，两类数据各自依次回退到东方财富和新浪。提供方响应经过股票身份校验后才会传给卡片。`storage` 权限用于保存自选股和提醒条件，`notifications` 权限用于显示触发通知。第三方公开接口可能延迟、限流、暂时不可用或变更格式；显示内容仅供个人观察，不构成投资建议。

以下命令仅供开发测试，普通安装不需要 Node.js 或 npm。在仓库根目录运行聚焦检查：

```sh
npm ci
npm test
node --check market-api.mjs
node --check background.js
node --check content.js
```

## 故障排查

如果面板没有出现，请确认网址以 `https://pc.zx017.net/vueapp/uc/chatting` 开头，重新加载扩展并刷新标签页。如果 Arc 在重新加载扩展后仍运行旧源码，请保持 `manifest.json` 的版本号与 `background.js` 中 `market-api.mjs?v=...` 的导入版本一致，再重新加载扩展并刷新聊天标签页。如果联想或行情不可用，可从 `chrome://extensions` 检查扩展的 service worker；公开数据接口也可能暂时不可用。页面较窄时，可以用面板箭头先将其收起再继续聊天。
